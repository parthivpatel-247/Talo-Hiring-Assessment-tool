Add a question

Write a question in plain language and paste the reference answer. On save, AI builds a sample-data table (for SQL) and a grading rubric — never shown to candidates.

Pick the part, write the question exactly as candidates should see it, and set its marks and word limit. AI reads each answer as a whole and gives marks with a short reason. A model answer and marking guidance can come with Bulk import; AI treats a model answer as one acceptable version. Tick Every candidate for a question everyone must get; the rest of the part is drawn at random.

Colleges

Rename or add colleges — used when uploading and for grouping

Edit the college names below. Renaming a college also updates every candidate already in it; removing one moves its candidates to Unassigned. Colleges are optional — you can remove them all, and uploads then go in as Unassigned. These names appear in the upload dropdown and the candidate filters.
